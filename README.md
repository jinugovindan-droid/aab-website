# Accounting Website

Static HTML website.

## Structure
- `aaccounting-website.html` — main page
- `assets/` — images and media
- `scripts/` — JavaScript
- `styles/` — CSS

## Local preview
Open `aaccounting-website.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000/aaccounting-website.html
```
